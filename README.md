# زاد المؤمن — Flutter starter

هذا مجلد تأسيسي أولي لتطبيق أندرويد باللغة العربية وبهوية خضراء وذهبية.

## ملاحظة مهمة
هذا ليس ملف APK جاهزاً. يحتاج المشروع إلى بناء سحابي باستخدام Flutter قبل تثبيته.

## بناء المشروع
1. ارفع محتويات هذا المجلد إلى مستودع GitHub خاص.
2. اربط المستودع بخدمة بناء Flutter سحابية مثل Codemagic.
3. اختر Android APK كنوع بناء.
4. بعد اكتمال البناء، نزّل APK وثبّته على هاتف Android.

## ضوابط المحتوى
- لا توجد آيات قرآنية تجريبية داخل هذا الإصدار.
- لن نضيف نص المصحف إلا من مصدر موثوق بعد مراجعة النص كاملاً والترخيص.
- القراء والتلاوات ستضاف بعد التحقق من الهوية والمصدر وحقوق الاستخدام.
- لا تُعرض مواقيت صلاة أو اتجاه قبلة على أنها دقيقة قبل إضافة الحساب والموقع والاختبارات.

## التشغيل محلياً (إذا توفر Flutter)
flutter pub get
flutter run
